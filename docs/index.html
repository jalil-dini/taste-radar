How it decides

1. Your tasteQloo turns what you named into entities, then asks which brands people with that taste over-index on.
2. The brand's own siteThe agent searches only the brand's own domain for a free-item page, opening it in a real browser when the form is drawn by script.
3. Five guard questionsA typed decision model asks: is it a real free offer for anyone? A sweepstakes? A cause sign-up? Members only? Outside your area? Anything doubtful is left out.
